# Commerce Cloud Integrations Homebrew tap

Formulae of [Commerce Cloud Integrations](https://www.commercecloudintegrations.com) tools.

## epx

[epx](https://github.com/commerce-cloud-integrations/emporix-cli) is a command-line client for
the Emporix Commerce APIs. On macOS or Linux (x64 or arm64):

```sh
brew install commerce-cloud-integrations/tap/epx
```

Homebrew installs the binary, its man pages (`man epx`) and shell completion for bash, zsh
and fish. Upgrade with `brew upgrade epx`.

The formula is written by the release workflow of epx for every release; changes made here
by hand are overwritten. Report problems in the
[epx repository](https://github.com/commerce-cloud-integrations/emporix-cli/issues).
